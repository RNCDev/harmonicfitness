# Workout log

One line per session: date, length, kit, voice, main movements, topics, then `format:` and `loads:` (movement = load and tempo, separated by semicolons). No injury details. The workout skill adds each line with `python3 tools/context.py log-session`, which checks the fields; `python3 tools/context.py check` lists any line the tools can't read.
