# The edit

Two writers wrote one audio workout: the coaching, and the stories in `[story]` ... `[/story]`. Read it as the listener will hear it, start to finish, and make it one coach talking to one person.

Change what doesn't sound like that coach: a join that jars, a story that starts cold, announces itself ("on this day", "news from") or ends on a moral, a line said twice, praise for something the coach couldn't see. Fix every issue the build's check names. Keep the rest as written.

Never change a movement, a dose, a safety line or limit cue, a marker, or a fact in a story; never add a story. Return only the segments you change, each whole, by its number.
