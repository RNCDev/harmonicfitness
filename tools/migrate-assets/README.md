# Migration assets

Files `./sweatcast migrate` needs from an older release, kept here (rather than read from git history)
so a zip download or a fork without tags migrates too.

- `v8-voices/`: the two coach clips sweatcast 8 shipped in `voices/` (Chatterbox Coach and Qwen3 Coach),
  byte for byte, so the 3 to 4 migration makes them the listener's coaches (Coach Julius and Coach Solo)
  with their measured pace and cached clips still matching. Removed in 10.0.0.
